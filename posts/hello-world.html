Hello World：这个博客是怎么搭起来的

2026-09-15 · Victor

这是这个博客的第一篇文章。整个站点没有用任何框架，纯手写 HTML / CSS / JS，托管在 GitHub Pages 上。

技术选择

没有构建工具，没有依赖，每个页面都是一个独立的 .html 文件，共用同一份 style.css 和一小段 theme.js 用来做深色模式切换。这样做的好处是：结构透明，随时可以打开文件直接看懂发生了什么。

目录结构

Victorgreatmarshal.github.io/
├── index.html       # 首页，文章列表
├── about.html       # 关于页
├── style.css        # 全站样式
├── theme.js         # 深色模式切换
└── posts/
    ├── hello-world.html
    └── why-static-site.html

如何发布新文章

复制 posts/ 下任意一篇文章作为模板，改标题和内容，再到 index.html 的文章列表里加一条链接，push 到 GitHub 就自动发布了。

没有数据库，没有后台，git push 即部署。
